# ♟️ Chess PGN Analyzer

محلل مباريات الشطرنج التفاعلي عبر الويب باستعمال صيغة **PGN (Portable Game Notation)**.

![License](https://img.shields.io/badge/license-MIT-blue.svg)
![Status](https://img.shields.io/badge/status-Active-brightgreen.svg)

## 🚀 المميزات (Features)

- **تحليل ملفات PGN:** استعراض المباراة بالكامل حركة بحركة.
- **سحب وإسقاط (Drag & Drop):** يمكنك سحب ملف `.pgn` وإسقاطه مباشرة فوق الرقعة.
- **تحكم بالكيبورد:** التنقل عبر الحركات باستخدام الأسهم.
- **مؤثرات صوتية:** أصوات تفاعلية خفيفة مع كل حركة.
- **تشغيل تلقائي (Autoplay):** عرض المباراة كفيديو تلقائي.
- **واجهة داكنة (Dark Mode):** تصميم مريح للعين ومتجاوب مع جميع الشاشات.

## 💻 التقنيات المستخدمة

- HTML5 / CSS3
- JavaScript (ES6)
- [chess.js](https://github.com/jhlywa/chess.js) - محرك قواعد الشطرنج
- [chessboard.js](https://chessboardjs.com/) - واجهة الرقعة التفاعلية
